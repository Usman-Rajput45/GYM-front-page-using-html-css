# GYM-Front-Page-Using-html-css

🏋️‍♂️ Gym Front Page (HTML & CSS)
Simple Frontend Project | Non-Responsive | Landing Page Design

A clean and modern Gym Front Page built using pure HTML & CSS, designed as a stylish landing page for fitness centers or gym websites.
This is a single-page frontend project (not responsive).
